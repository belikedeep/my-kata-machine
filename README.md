# My Kata Machine

A simple and configurable environment for practicing data structures and algorithms (DSAs) using TypeScript.

## Project Structure

- `algo.config.js`: A simple list of the katas you want to generate.
- `scripts/dsa.js`: Defines the function signatures and types for each kata.
- `scripts/generator.js`: The script that generates all katas into `src/practice/`.
- `src/`: Contains the generated source code for your katas.
- `tests/`: Contains the test files for your katas.
